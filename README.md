# בית המקדש — Beis Hamikdash 3D Explorer

A first-person 3D walkthrough of the Holy Temple in Jerusalem.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the app
npm run dev
```

Then open **http://localhost:5173** in your browser.

## Controls

| Key | Action |
|-----|--------|
| `W` / `↑` | Walk forward |
| `S` / `↓` | Walk backward |
| `A` / `←` | Strafe left |
| `D` / `→` | Strafe right |
| `Mouse` | Look around |
| `Click` | Capture mouse |
| `Esc` | Release mouse |

## What's Inside

### Areas
- **Har HaBayis** — Temple Mount outer courtyard
- **Ezras Nashim** — Women's Court (starting position)
- **Azaras Yisrael** — Court of Israelites
- **Azaras Kohanim** — Court of Kohanim
- **Ulam** — Entrance Hall with pillars
- **Heichal** — Sanctuary
- **Kodesh HaKodashim** — Holy of Holies

### Keilim (Holy Vessels)
- **Mizbeiach HaOlah** — Outer Altar (32×32 amos)
- **Kiyor** — Copper Laver
- **Menorah** — Seven-branched candelabrum (with lights!)
- **Shulchan** — Showbread Table with 12 loaves
- **Mizbeiach HaZahav** — Golden Incense Altar
- **Aron HaKodesh** — Holy Ark with Keruvim

### HUD
- Minimap (top-left)
- Compass (top-center)
- Location info (bottom-left)
- Kli descriptions (top-right, when nearby)
